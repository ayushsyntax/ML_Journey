# ML Kaggle Notebooks

A curated collection of machine learning notebooks focused on practical applications, Kaggle competition strategies, and core ML concepts. This repository is intended for learners and practitioners who aim to build robust and generalizable models using a structured approach.

---

## Repository Overview

### Core ML Practices
- `50_Q&A_in_ML.ipynb` — Most asked ML questions with concise answers.
- `Mistake_Done_in_ML.ipynb` — Common mistakes and how to avoid them.
- `How_to_Approach_Machine_Learning_Project.ipynb` — ML project planning and lifecycle.
- `Data_Scientist.ipynb` — Bash, Python, and Pandas essentials.

### Model Evaluation and Theory
- `Loss_Function_vs_Cost_Function.ipynb`
- `evaluation_metrics.ipynb`, `Evaluation_Metrics_for_MultiTarget_Classification.ipynb`
- `Bias_Variance_Tradeoff_in_Machine_Learning.ipynb`
- `ROC_AUC_in_ML.ipynb`

### Ensemble Learning
- `Bagging_vs_Boosting.ipynb`, `Ensemble_Learning_and_its_Types.ipynb`
- `Voting_Ensemble.ipynb`, `Stacking_and_Blending_in_ML.ipynb`
- `Adaboost_vs_GradientBoosting.ipynb`
- `Xgboost_Classification.ipynb`, `Xgboost_Regression.ipynb`

### Regression Techniques
- `LinearRegression_learning.ipynb`, `MultipleLinearRegression_from_Scratch.ipynb`
- `Lasso`, `Ridge`, `ElasticNet`, `Polynomial_Logistic_Regression.ipynb`
- `Logistic_vs_SVM.ipynb`, `Softmax_Regression_in_ML.ipynb`

### Algorithm Implementations
- `Gradient_Descent_in_ML.ipynb`
- `batch`, `mini_batch`, `stochastic_gradient_descent_from_scratch.ipynb`
- `Support_Vector_Machine.ipynb`, `Kernel_Trick_SVM.ipynb`
- `Naive_Bayes`, `KNN`, `DecisionTrees`, `RandomForest`, `GBM`

### Clustering and Unsupervised Learning
- `KMeans_from_Scratch.ipynb`, `DBSCAN_Working.ipynb`
- `Hierarchical_Clustering.ipynb`, `IrisDataset(Clustering).ipynb`
- `Unsupervised_Techniques.ipynb`, `Unsupervised_Learning_and_Recommendation.ipynb`

### Feature Engineering & Data Transformation
- `Feature_Importance`, `FeatureEngineering(Normalization & Standardized)`
- `F_E(Binning, Pipelines, Label_Encoding, PCA...)`
- `Fairness_in_ML.ipynb`

### Optimization and Hyperparameter Tuning
- `Bayesian_Optimization_in_ML.ipynb`, `Optuna_basics_Working.ipynb`
- `Hyperparameter_Tuning` for AdaBoost, RandomForest, and others
